# Contributing to Control Drift

First off, thank you for considering contributing to Control Drift! It's people like you that make open-source security tools powerful.

## Development Setup

1. **Prerequisites:** Make sure you have [Node.js](https://nodejs.org/) (v18+) installed.
2. **Install Dependencies:** Run `npm install`
3. **Start the Dev Server:** Run `npm run dev`

## Testing

Control Drift takes reliability seriously. Please ensure tests pass before submitting a Pull Request.

- **Unit Tests:** `npm run test`
- **End-to-End Tests:** `npm run test:e2e` (Ensure your local dev server is running before executing).

## Pull Request Process

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Update the documentation if you've changed behavior.
4. Ensure your code follows the existing style and is formatted nicely.
5. Issue the pull request!

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
